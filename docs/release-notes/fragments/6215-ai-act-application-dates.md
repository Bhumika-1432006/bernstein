## The compliance report prints the AI Act date for the system's own category

`bernstein compliance assess` and `report` used to print "August 2027 (Article 111(2))" for every high-risk system. Article 111(2) is a grandfathering clause, not an application date, and the date was not the one that applies. The report now reads each date from one table, `src/bernstein/compliance/ai_act_dates.py`, which quotes the Official Journal text of Regulation (EU) 2024/1689 as amended by Regulation (EU) 2026/1744 beside every date and records the day it was checked. An Annex III system gets 2 December 2027, an Annex I system 2 August 2028, and any system with an Article 50 trigger also gets the Article 50 date (2 August 2026). `SystemDescriptor` has a new `annex_i_product_component` flag for the Annex I route. The report carries `application_dates` and `application_dates_as_of`; the existing `deadline` string is still there and now names the provision. A test fails if another module writes one of these dates, or if a row is edited without its quoted text (#6215). The `article-50` evidence pack from the same issue is not part of this change.
