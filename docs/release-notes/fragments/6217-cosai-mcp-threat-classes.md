## The CoSAI evidence pack maps the twelve MCP threat classes

`bernstein audit export --standard cosai` now includes a row for each of the twelve threat classes (`MCP-T1` to `MCP-T12`) of the CoSAI white paper *Model Context Protocol (MCP) Security*, so the answer to "which published MCP threat taxonomy do these controls map to" no longer has to be derived by hand for each questionnaire. Each row carries the paper's class title and a stable `mcp-threats.tN-...` id, and the paper's version and date are recorded because its numbering may still change. None of the twelve is `mapped`: the MCP signing and scan gate runs before a third-party server is spawned but its verdicts are not written to the audit chain, so a class that depends on them is `partial` and states what is missing. Only chain events that production code emits are cited, which leaves out `mcp.task_handle` (its recorder has no caller yet). The pack's `controls_partial` count rises from 4 to 16 (#6217).
